# Hardware Parts List

- Adafruit QT Py S3 PSRAM
- Square Force-Sensitive Resistor (FSR) - Alpha MF02A-N-221-A01
- 22k resistor

Purpose: phone stand that can detect if you put your phone on it or take it offers; communicate the status to the flutter app via Bluetooth

## Wiring:
3V  ---- FSR ----+---- A2 or A3
                 |
               22 kΩ
                 |
GND -------------+
